# Streaming Distribution Package

This folder is the upload package for the public Zombieland soundtrack. It
contains metadata, artwork, and public copy only; the upload masters remain the
WAV files in the sibling `relax/` and `tense/` folders.

## Releases

| Release | Source masters | Tracks | Total duration | Artwork |
| --- | --- | ---: | ---: | --- |
| `Zombieland - Calm` | `../relax/` | 22 | 1:10:30 | `artwork/zombieland-calm-cover.jpg` |
| `Zombieland - Tense` | `../tense/` | 20 | 1:06:36 | `artwork/zombieland-tense-cover.jpg` |

Use the detailed, paste-ready metadata in `METADATA.md` when submitting the
releases through the distributor. Track titles omit the repeated `Zombieland –`
filename prefix, because the artist and album already identify their context.

## Upload Rules

- Artist: `Brrainz`
- Label: `Brrainz`
- Contact: `info@brrai.nz`
- All masters are original Suno Pro outputs owned by Brrainz and licensed for
  commercial distribution.
- Mark each track as AI-generated in the distributor's AI-credit flow. Select
  AI music/audio, and select AI lyrics only where Suno generated the lyrics.
- Do not opt into YouTube Content ID or equivalent social-media fingerprinting
  for the initial release. The music already ships in the Zombieland mod and
  could otherwise claim player and project videos.

## Master Audit

The 42 source masters were checked on 2026-07-19. Each is a stereo 48 kHz
16-bit PCM WAV (`pcm_s16le`). Loudness policy and the deliberate Fogfront
Outpost exception remain owned by `../LOUDNESS_NOTES.md`.
